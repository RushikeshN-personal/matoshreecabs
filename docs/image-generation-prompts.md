# Image Generation Prompts — Matoshree Cabs

Every image currently used on the site is hotlinked from Wikimedia Commons (or points at a
local file that doesn't exist). This doc lists **all 46 distinct images**, grouped exactly as
requested, with one standalone AI-image-generation prompt per image. Paste each prompt into
Midjourney / DALL·E / Stable Diffusion / Firefly one at a time.

**Global style guardrails to keep the set consistent** — repeat these in every prompt if your
tool doesn't support a shared style reference:
- Photorealistic, natural daylight (unless stated otherwise), no text/watermarks/logos in frame
- Warm, slightly saturated colo r grading that pairs with the site's orange (#ea580c) / white brand
- No people's faces in close-up (avoid likeness/generation issues) — candid, small, or absent
- Vehicles: describe by body shape/color only, never brand name badges, to dodge trademarked logo artifacts

Not included below: `/logo.png` — that's your own real uploaded asset, not generated.
